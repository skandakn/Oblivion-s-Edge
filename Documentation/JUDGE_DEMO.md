# Judge demo: Oblivion's Edge (80 seconds)

## 0:00–0:10 — Establish the horror

Open on the Main Menu, show Controls briefly, then start. Walk through the dark station with the HUD visible. Call out the restrained blue-violet telemetry and the readable vitals display.

## 0:10–0:25 — Mathematics and retrieval

Open the weapon note and solve the first directional/angle puzzle. Deliberately enter one incorrect answer to show failure feedback, then solve it. Collect Edge and Handle; the HUD marks each component `ONLINE`.

## 0:25–0:40 — Boss combat

Enter the alien arena. Fire and reload once to show ammunition changing. Let the boss attack once to show player health reacting. Break armor and retrieve Core; point out the boss armor bar and exposed-core alert.

## 0:40–1:00 — 60-second DeathStorm sequence

Start crafting when Core is collected. Show the countdown and Core Alignment instruction. Solve Edge Synchronisation and Energy Stabilisation. If a prepared alternate save is available, show a timer expiry for the enrage warning, then resume from the successful save.

## 1:00–1:20 — Finish and close

Equip DeathStorm, stun the boss, and strike the final weak point. Hold on the Victory screen, then return to the menu with the scene-transition control.

Prepare two saves: one immediately before Core collection and one before the final weak-point strike. This keeps the judge run within 60–90 seconds while preserving the timeout/enrage path for a quick alternate demonstration.
